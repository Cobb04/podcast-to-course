# AI 应用生存检查表

适用场景：季度战略会、融资前审计、模型重大升级后、竞品突然爆发时。

## A. 上游重力

- [ ] 下一次模型升级最可能免费覆盖我们的哪三项价值？
- [ ] 上游成本下降会扩大毛利，还是立刻被竞争传导给用户？
- [ ] 如果模型厂商推出相同界面，用户留下的理由是什么？
- [ ] 我们是在增强模型，还是只在重新包装模型？

## B. PMF 与窗口

- [ ] 当前信号是持续留存，还是注意力峰值？
- [ ] 市场增量正在爆发，还是我们只是被融资新闻放大？
- [ ] 哪个差异能形成口碑传播？它的有效期估计多久？
- [ ] 为了抢窗口，可以牺牲什么；绝不能牺牲什么？

## C. 单位经济

- [ ] 现金流为正是否主要来自年付预收款？
- [ ] 毛利是在真实消耗后计算，还是按理论额度计算？
- [ ] 高活跃用户会让产品更赚钱，还是越用越亏？
- [ ] 续费率、Token 消耗率、模型成本同时向坏处变化时还能否存活？
- [ ] 有没有把「用户没用完」误写成「用户很满意」？

## D. 时间—空间—资源—壁垒

- [ ] 巨头为什么暂时不会把全部优先级放在这个场景？
- [ ] 垂直界面或工作流是否真的改变任务完成方式？
- [ ] 用户与收入正在沉淀哪些可支配资源？
- [ ] 哪项价值需要一年积累，不能由一次模型升级瞬间复制？
- [ ] 用户是否向其他用户或平台贡献不可替代价值？

## E. 组织承载

- [ ] 现在的交付问题是能力、角色、目标还是协作问题？
- [ ] 创始人的关键判断能否被团队复述和反驳？
- [ ] 角色调整是否同时完成业务判断与尊重机制？
- [ ] 同类事故是否已经发生两次？若是，停止把它叫偶发。
- [ ] 当前最短的组织短板会不会让战略窗口白抢？

## F. 最终排序

只选一个当前优先级：

- [ ] **止血：** 单位经济或现金 runway 威胁生命。
- [ ] **抢窗：** 市场窗口短，且已有足够证据。
- [ ] **转化：** 增长存在，但尚未沉淀资源。
- [ ] **筑垒：** 有资源，缺网络效应或迁移成本。
- [ ] **补短板：** 战略正确，但组织无法稳定交付。

> 如果五项都勾了，你不是优先级很多；你是还没有做优先级。
