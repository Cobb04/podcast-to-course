# 术语表

| 术语 | 一句话解释 | 在本期什么时候重要 |
|---|---|---|
| **PMF** | Product-Market Fit，产品已经解决真实需求并出现持续使用/付费信号 | 讨论「第一个发现 PMF」为何不等于最终赢 |
| **ARR** | Annual Recurring Revenue，按当前订阅节奏折算的年度经常性收入 | 评估高速增长时，注意它不等于已收到或已审计收入 |
| **Token** | 模型处理输入与生成输出的计费/计算单位 | AI 产品成本会随用户使用深度直接变化 |
| **LTV** | 用户在完整生命周期为产品贡献的总价值 | 年付、续费率和使用频率共同决定 LTV |
| **毛利** | 收入扣除直接交付成本后剩余的比例 | 低价策略能否在模型成本波动下活下来 |
| **Breakage** | 用户购买但没有使用掉的额度或权益 | 订阅利润可能部分来自未消耗积分 |
| **Usage-based pricing** | 按实际使用量收费 | 解决高 Token 消耗用户与固定订阅的冲突 |
| **Freemium** | 免费基础服务 + 付费升级 | 免费用户会产生模型成本，使 AI 产品免费试用更昂贵 |
| **GTM** | Go-To-Market，产品进入市场、获客和销售的整套方式 | 饱和式信息传播属于 GTM，不等于效果广告投流 |
| **自然增长** | 非直接付费效果广告带来的用户增长 | 嘉宾称自然获客占比高，但品牌投入归因边界需要说明 |
| **双边网络** | 两类用户彼此创造价值，参与者越多平台越有用 | 被提出为应用公司可能的「长江天险」 |
| **网络效应** | 用户数量增长会直接提升其他用户获得的价值 | 区分单纯用户规模与真正壁垒 |
| **Reward model** | 用什么标准奖励、惩罚或选择行为 | 本期既用于 AI 判断，也用于组织岗位与尊重机制 |
| **AI-native 人才** | 工作方式天然利用 AI，并能快速适应模型变化的人 | 嘉宾描述应用公司的人才筛选目标 |
| **Context** | 模型完成任务所需的背景、资料和状态 | Lovart 从工作流走向 Agentic 产品的重要输入 |
| **Agentic** | 系统能自主规划并调用工具完成多步任务 | 新模型把部分人工工作流内化后出现的产品方向 |
