# 框架卡：时间—空间—资源—壁垒

**一句话：** 垂直 AI 应用不能只利用巨头留下的缝隙；它必须把短暂窗口连续转换成垂直心智、可支配资源和复利壁垒。

**来源：** 陈冕关于「逐鹿中原、占领江东、修长江天险」的战略比喻。`🟡 创业竞争经验 + 尚未完全验证的战略假说`

## 什么时候用

- 你在评估一个「大模型之上的应用层」创业项目。
- 产品增长很快，但团队说不清楚长期护城河。
- 上游模型厂商正在进入相邻场景。
- 投资人或团队问：「这不就是套壳吗？」

## 四次转换

```text
① 时间窗口
巨头有更高优先级的通用战场
        │ 必须转换，否则窗口关闭
        ▼
② 垂直空间
独特界面 · 专业工作流 · 品牌心智
        │ 必须沉淀，否则只是流量
        ▼
③ 可支配资源
用户 · 收入 · 内容 · 数据 · 组织能力
        │ 必须复利，否则只是规模
        ▼
④ 长期壁垒
网络效应 · 迁移成本 · 供给生态 · 用户共创
```

## 每一层的判断规则

### 1. 时间窗口：为什么巨头现在不全力做？

- 好答案：它会破坏通用产品纯粹性；需要不同界面、销售或供给；巨头正忙于更大主战场。
- 坏答案：巨头还没想到；我们比他们聪明；他们看不上小市场。
- 升级条件：窗口长度足以完成下一层产品与心智建设。

### 2. 垂直空间：用户为什么在这里而不是通用助手里完成任务？

- 好答案：需要专业画布、协作、资产管理、领域反馈或连续工作流。
- 坏答案：我们的按钮更多；本周接入了一个新模型；价格更便宜。
- 升级条件：用户因场景心智而来，不只是因一次促销或模型首发而来。

### 3. 可支配资源：增长留下了什么？

- 好答案：经常使用的工作流、独家供给、可续费收入、创作者关系、组织 know-how。
- 坏答案：注册用户、媒体声量、峰值 ARR 截图。
- 升级条件：资源能被投入长期建设，而不只是填补上游 Token 成本。

### 4. 长期壁垒：用户越多，产品是否越不可替代？

- 好答案：供给更丰富、协作网络更强、反馈数据更好、迁移损失更大。
- 坏答案：用户多所以品牌大；我们会以后再想护城河。
- 完成条件：即使上游模型免费提供相似能力，用户仍因平台内积累留下。

## 什么时候不要用

- 上游模型能力本身就是你的独家技术，不需要依赖巨头缝隙。
- 业务是短期套利，团队并不追求独立长期公司。
- 场景受强监管、渠道或供应链约束，决定胜负的不是软件网络效应。
- 还没有基本 PMF；此时谈长江天险容易变成战略角色扮演。

## 一页诊断

| 问题 | 是 | 否 |
|---|---|---|
| 上游升级会增强我们，而不是直接替代我们？ | 继续 | 回到时间窗口 |
| 用户在此完成通用助手不适合的任务？ | 继续 | 垂直空间不足 |
| 增长正在留下内容、数据、收入或关系资产？ | 继续 | 流量尚未变资源 |
| 用户越多，其他用户获得的价值越高？ | 初见壁垒 | 仍处资源层 |

## 边界条件

这个框架来自嘉宾对 Evoken 路径的解释，不能证明 Evoken 已经建成壁垒。嘉宾在节目中明确承认 LibTV 当时尚未形成明显双边网络，最终产品形态仍会变化。因此它最适合做「战略审计表」，不适合做「成功宣言」。
