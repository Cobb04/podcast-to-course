# Module 3: 用时间换空间，再把空间浇成壁垒

## Teaching Arc

- **Metaphor:** 直接使用陈冕的三国地理图：巨头逐鹿中原，创业公司先占巴蜀/江东，再修自己的长江天险。
- **Opening hook:** 巨头看见你，不等于巨头会立刻把全部兵力调来打你。
- **Key insight:** 垂直创业的战略链条是「时间窗口 → 垂直空间 → 用户/收入资源 → 复利型壁垒」；每一环都必须转换，停在任何一环都只是暂住。
- **Why should I care?:** 用于判断垂直 AI 产品是否真的有独立生存路径，而不只是模型 API 上的一层 UI。

## Pre-extracted Quotes and Claims

- **01:30:59–01:33:49 · 陈冕:** 「如何用时间换来空间，再用空间换来资源，再用资源浇筑壁垒，是每一个创业公司如果要独立存活，最重要的战略问题。」
- **01:34:01 · 陈冕:** 多模态创作和文字通用助手之间的界面与心智差异，像早期的「蜀道」，但还不是长江。
- **01:35:19 · 陈冕:** 「我修出来，我才知道它是不是 work。」
- 🟡 **Medium:** 框架来自创业竞争实践与历史类比，有可操作价值。
- 🔴 **Low:** 「巨头优先级缝隙」的长度与胜率无法从访谈验证，嘉宾自己也承认概率未知。

## Interactive Elements

- [x] Framework visualization：四层逐步展开——时间、空间、资源、壁垒。
- [x] Quote ↔ insight：壁垒不是发现出来的，是用资源长期浇筑出来的。
- [x] Insight table：每一层的证据、假象和升级条件。
- [x] Quiz：垂类产品有用户增长但无用户间价值，当前卡在哪一层？
