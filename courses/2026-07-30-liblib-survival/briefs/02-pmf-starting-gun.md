# Module 2: PMF 只是枪响，不是颁奖礼

## Teaching Arc

- **Metaphor:** 找到 PMF 像听见发令枪；第一个起跑的人值得奖励，但领奖台不会因此预留。
- **Opening hook:** 「第一个做出来」和「最后赢」之间，隔着增长窗口、产品体验、注意力与组织交付。
- **Key insight:** 陈冕的打法是先验证市场是否足够大，再在注意力窗口内做出可传播差异，并用饱和式信息攻击抢增量。
- **Why should I care?:** 帮助团队判断何时应该继续原创探索，何时应该承认市场信号并快速执行。

## Pre-extracted Quotes and Claims

- **00:37:09 · 陈冕:** 「第一个发现 PMF，在人类科技竞争的历史上，和最终赢得这个市场是差着十万八千里的。」
- **00:41:02 · 陈冕:** 「所有工程上的创新，它的时效性几天、一个礼拜……模型的竞争都是一个月就没有了。」
- **00:45:36 · 陈冕:** 「哪怕你找到一个 PMF 也应该很警惕……如果增量爆发时没有抢到足够多的增量，你的存量没有意义。」
- **00:46:06 · 陈冕:** LibTV 上线后很快从零达到单日十万美元收入峰值；该数字为嘉宾自述。
- 🟡 **Medium:** 时间窗口与注意力策略来自三款产品的直接操盘经验。
- 🔴 **Low:** 工程差异只保持一周、存量「没有意义」是强表达，缺少系统数据支持。

## Interactive Elements

- [x] Conversation flow：主播追问「借鉴」→ 嘉宾承认非首个 PMF → 把争论推进到执行与市场窗口。
- [x] Quote ↔ insight：先发奖励不等于终局所有权。
- [x] Framework reveal：信号 → 窗口 → 增量。
- [x] Quiz：竞品已证明 PMF，你是继续闭门原创还是快速进入？加入边界条件。
